## Featured Projects

### ⏱️ TimePilot

**A local-first productivity and time-management Chrome extension.**

Built with **React, TypeScript, Tailwind CSS, Vite, and Chrome Manifest V3**.

* Scheduled activities and reminders
* Focus sessions and countdown timers
* Website blocking
* Reusable routines
* Productivity insights
* Light / dark / system themes
* Local-first architecture
* No accounts, cloud services, telemetry, or external APIs
* Automated browser audit flows and unit tests
